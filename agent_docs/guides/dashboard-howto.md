# CEO24 — как пользоваться дашбордом

> Практическая инструкция для команды: как читать раздел **Dashboard**, на что
> смотреть и как реагировать на отклонения.
>
> Дополняет `dashboard-metrics.md` (там — точные определения каждого показателя).
> Эта же инструкция опубликована в чате «Бухгалтерия» Bitrix24.

**Доступ:** https://ceo.pass24pro.ru — вход по личному логину.
**Совет:** наведите курсор на любую плитку (значок ⓘ) — всплывёт подсказка
с пояснением показателя и тем, как реагировать на отклонения.

---

## Откуда цифры

Два источника:

- **1С** — бухгалтерский факт (плитка «Долг»).
- **Аналитика CEO24** — собираемость и структура.

Собираемость считается по тому, **за какой месяц** заплатили, а не когда пришли
деньги. Платёж за март, пришедший в мае, засчитывается марту.

---

## 🟦 Блок «Финансы»

**MRR факт · <месяц>** — сколько абонплаты собрали за последний закрытый месяц.
Норма — **90%+**. Плитка окрашена по собираемости (жёлтая/красная = ниже нормы).
*Реакция:* ниже нормы — усилить взыскание, разобрать крупных должников.

**MRR план** — сколько абонплаты должно приходить в месяц при 100% оплате.
*Реакция:* падение = отток клиентов или урезание тарифов.

**Сбор · <месяц> (текущий)** — сколько собрано за идущий месяц.
*Реакция:* сравните % сбора с долей прошедших дней («день 19/31»). % отстаёт
от доли дней → риск недосбора к концу месяца.

**Долг** — сколько должны компании сейчас (по 1С). Подпись «90+» — доля
застарелого долга. *Реакция:* рост долга и высокая доля 90+ — активизировать
взыскание.

---

## 🟩 Блок «Клиентская база»

- **Активные клиенты** — общая база.
- **Новые · <прошлый месяц>** / **Новые · <текущий месяц>** — сколько клиентов
  впервые заплатили.
- **Отток с начала года** — клиенты со статусом «Отток» (проставляется вручную
  после сверки в 1С). Считается по статусу, а не по дате платежа.
- **Активные с просрочкой** — активные клиенты, не платившие >60 дней и не
  оплатившие вперёд. *Реакция:* сигнал для взыскания (не отток), разбирать в «Должниках».
- **Churn rate** — доля оттока. *Реакция:* рост — разбирать причины ухода,
  удерживать клиентов.

📌 Главное: приток новых должен обгонять отток.

---

## 📈 Графики

**Собираемость по месяцам** — столбик = собрано, пунктир = начислено. Селектор
справа переключает год. Зелёный ≥95%, оранжевый 70–95%, красный <70%.
*Смотрим:* есть ли красные месяцы, тренд вверх/вниз.

**Структура долга** — долг по возрасту: 0–30 / 31–60 / 61–90 / 90+ дней неоплаты.
Каждый клиент в одной корзине, сумма корзин = плитке «Долг». Клик по корзине →
список должников. *Смотрим:* свежие корзины (0–90) — кто начал недоплачивать
сейчас, с ними работать в первую очередь, пока долг молодой.

**Структура поступлений** — откуда деньги: текущий период / погашение долга /
аванс / разовое. Здоровая картина — преобладание «текущего» и «аванса».

---

## 🔔 Требуют внимания

Сигналы системы (клиенты без менеджера и т.п.), сгруппированы по важности.
Клик по строке ведёт в нужный раздел.

---

## ✅ Что проверять каждый день (за 1 минуту)

1. **MRR факт** — собираемость выше 90%? (цвет плитки подскажет)
2. **Сбор текущего месяца** — % обгоняет долю прошедших дней?
3. **Долг** — растёт ли, какая доля 90+?
4. **Клиентская база** — приток новых обгоняет отток?
5. **Графики** — есть ли красные месяцы, свежие должники в корзинах 0–90?

---

## 🎨 Цвета процентов

🔴 <30% · 🟠 30–50% · 🟡 50–80% · 🟢 80–100%
