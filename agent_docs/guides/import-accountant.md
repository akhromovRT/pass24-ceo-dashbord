# Инструкция для бухгалтера: импорт выгрузок 1С в CEO24

Документ для бухгалтера ООО «ОНВИ СЕРВИС». Описывает, **какие файлы**, **когда** и **как**
загружать в систему CEO24, и **где потом проверять** результат.

Кратких знаний компьютера достаточно — вся работа в браузере. Программистом быть не нужно.

---

## 1. Что от вас требуется (коротко)


| Когда                                         | Что выгрузить из 1С               | Тип файла в системе              |
| --------------------------------------------- | --------------------------------- | -------------------------------- |
| **Каждый рабочий день**                       | Отчёт «Оплата от покупателей»     | `Оплата от покупателей (1С)`     |
| **Раз в неделю** (например, по понедельникам) | Отчёт «Задолженность покупателей» | `Задолженность покупателей (1С)` |
| По необходимости (необязательно)              | Банковская выписка                | `Банковская выписка`             |


Один файл за раз. Порядок действий всегда один и тот же — он описан в разделах 3–5.

---

## 2. Зачем это нужно

CEO24 — управленческая система: дашборд для директора, реестр клиентов, контроль должников
и собираемости абонентской платы. **1С остаётся главной системой учёта.** CEO24 не подключён
к 1С напрямую — он получает данные из файлов-выгрузок, которые загружаете вы.

- **«Оплата от покупателей»** — история входящих платежей. Питает метрику собираемости и
«структуру поступлений» на дашборде. Платежи приходят каждый день — поэтому файл загружается
**ежедневно**, чтобы дашборд был свежим.
- **«Задолженность покупателей»** — полный срез долгов, договоров и реализаций. Это тяжёлый
отчёт; долги меняются медленнее платежей — поэтому достаточно **раза в неделю**.

Если вы день-два не загрузили файл — ничего не сломается, данные просто будут чуть устаревшими.
Загрузите позже — система сама подхватит всё пропущенное.

---

## 3. Шаг 1. Подготовить выгрузку из 1С

### 3.1. «Оплата от покупателей» (ежедневно)

1. В 1С сформировать отчёт/реестр **«Оплата от покупателей»** за период **с 1 января текущего
  года по сегодняшний день**.
2. Выгрузить (сохранить) его в **Excel** — файл `.xlsx` (или `.xls`).
3. Рекомендуемое имя файла: `Оплата_от_покупателей_ГГГГ-ММ-ДД.xlsx`
  (например `Оплата_от_покупателей_2026-05-19.xlsx`) — имя видно в истории импортов.

> **Почему «с начала года», а не «за сегодня»?** Так надёжнее: система сама отбросит платежи,
> которые уже загружала ранее, и добавит только новые. Задвоить данные перезаливкой невозможно.

### 3.2. «Задолженность покупателей» (еженедельно)

1. В 1С сформировать отчёт **«Задолженность покупателей»** за **текущий год**.
2. Отчёт должен быть в **стандартном виде** — с тремя раскрытыми уровнями:
  **Покупатель → Договор → Документ** (Реализация / Поступление). Группировки **не сворачивать**.
3. Выгрузить в **Excel** (`.xls` или `.xlsx`).
4. Рекомендуемое имя файла: `Задолженность_покупателей_ГГГГ-ММ-ДД.xlsx`.

### 3.3. Общие требования к файлам

- Формат — только `**.xlsx` или `.xls`**. Не `.csv`, не `.ods`, не `.pdf`.
- Размер файла — **до 10 МБ** (обычные выгрузки укладываются с большим запасом).
- **Не менять состав, порядок и названия колонок** отчёта, не добавлять свои столбцы, не
переставлять листы. Система читает файл по фиксированной структуре — если изменить вид
отчёта, импорт не пройдёт (см. раздел 8, ошибка «Parse error»).
- Выгружать отчёт «как есть» из 1С, не редактировать его вручную в Excel.

---

## 4. Шаг 2. Загрузить файл в CEO24

1. Открыть в браузере (Chrome или Edge) адрес: **[https://ceo.pass24pro.ru](http://ceo.pass24pro.ru)**
2. Войти: ввести **email и пароль**, выданные администратором.
  *Если входа нет или пароль не подходит — обратитесь к администратору (см. раздел 10).*
3. В меню слева нажать **«Импорт»**.
4. **Сначала** выбрать в поле **«Тип файла»** нужный тип:
  - `Оплата от покупателей (1С)` — для ежедневной выгрузки платежей;
  - `Задолженность покупателей (1С)` — для еженедельной выгрузки долгов;
  - `Банковская выписка` — только для сверки (см. раздел 7).
  > ⚠️ **Тип файла выбирается ДО выбора файла.** Загрузка стартует автоматически сразу
  > после выбора файла — если тип указан неверно, данные уйдут не туда.
5. Нажать кнопку **«Выбрать .xls / .xlsx»** и указать подготовленный файл.
  Загрузка начнётся **сразу** после выбора.
6. Дождаться результата (обычно несколько секунд, для больших файлов — до полминуты;
  вкладку не закрывать):
  - 🟢 **Зелёное сообщение** «Импорт завершён: … организаций, … контрактов, … документов.
  Новых: …» — успех, переходите к разделу 5.
  - 🔴 **Красное сообщение** — ошибка. Что делать — в разделе 8.

---

## 5. Шаг 3. Проверить, что импорт прошёл

### 5.1. История импортов

Сразу после загрузки, на том же экране **«Импорт»**, внизу — таблица **«История импортов»**.
Ваш файл должен появиться **первой строкой**. Проверьте:


| Колонка                                | Что должно быть                                                          |
| -------------------------------------- | ------------------------------------------------------------------------ |
| **Файл**                               | имя загруженного файла                                                   |
| **Источник**                           | `Оплаты` / `1С (задолженность)` / `Банк` — соответствует выбранному типу |
| **Статус**                             | `**completed`** (зелёный). `failed` — импорт не прошёл, см. раздел 8     |
| **Организации / Договоры / Документы** | числа больше нуля                                                        |
| **Новых**                              | сколько новых клиентов появилось — см. ниже                              |
| **Дата**                               | сегодняшние дата и время                                                 |


### 5.2. Колонка «Новых» — на что обратить внимание

«Новых» — это клиенты с ИНН, которых раньше в системе не было; система завела для них
карточки автоматически. Это нормально, но:

- если **«Новых» больше нуля** — сообщите руководителю продаж: новым клиентам нужно назначить
менеджера. В системе по ним создаётся пометка «Новый клиент без менеджера»
(видна на дашборде в панели «Требуют внимания»).
- если «Новых» неожиданно много (десятки) — возможно, в выгрузку попали лишние данные или
другой период; перепроверьте файл.

## 6. Где смотреть результат после импорта

После успешного импорта данные сразу отражаются на рабочих экранах. **Платежи и долги
обновляют разные экраны** — проверяйте тот, что относится к загруженному файлу.

### После загрузки «Оплата от покупателей» (ежедневно)


| Экран (меню слева)                                                    | Что проверить                                                                                                                                           |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Дашборд**                                                           | График **«Собираемость»** — текущий месяц обновился. Блок **«Структура поступлений»** — сегодняшние платежи учтены. KPI «Собрано в этом месяце» подрос. |
| **Карточка клиента** (открыть из «Реестра клиентов» кликом по строке) | Вкладки **«Помесячно»** и **«Расчёты»** — новый платёж разнесён по месяцам начислений.                                                                  |


### После загрузки «Задолженность покупателей» (еженедельно)


| Экран (меню слева)  | Что проверить                                                                         |
| ------------------- | ------------------------------------------------------------------------------------- |
| **Должники**        | Список должников и суммы долга обновились.                                            |
| **Реестр клиентов** | Сумма долга по клиентам, сегменты в шапке (платят / частично / не платят / должники). |
| **Дашборд**         | Панель **«Просрочка»** (aging) и KPI по долгу.                                        |


> Если числа на экранах не изменились — проверьте, что в истории импортов статус `completed`
> и что вы открыли экран **заново** (обновите страницу клавишей F5).

---

## 7. Банковская выписка (необязательно)

Банковская выписка — это файл из **банк-клиента** (не из 1С). В CEO24 её можно загрузить
с типом `Банковская выписка`, порядок действий тот же (раздел 4).

**Важно понимать границы:**

- Метрику **собираемости** и денежные показатели дашборда считает **только** отчёт
«Оплата от покупателей» из 1С. Банковская выписка на эти цифры **не влияет** и **не заменяет**
ежедневную выгрузку платежей.
- Загрузка выписки нужна лишь как вспомогательный инструмент: завести карточки по новым ИНН
из банка или свериться вручную.
- Двойного учёта не возникает: выписка и «Оплата от покупателей» хранятся как отдельные
источники. Но и пользы для дашборда от выписки нет.

**Вывод:** в обычной ежедневной/еженедельной рутине банковская выписка не нужна. Загружайте
её только по отдельной просьбе руководителя или администратора.

## 8. Если что-то пошло не так


| Сообщение / ситуация                                              | Что это значит                                                                                                | Что делать                                                                                                                             |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 🔴 **«Only .xls/.xlsx files accepted»**                           | Файл не в формате Excel (например `.csv`, `.pdf`)                                                             | Пересохранить выгрузку из 1С как `.xlsx` и загрузить снова                                                                             |
| 🔴 **«File already imported»**                                    | Этот файл целиком уже загружали раньше                                                                        | **Это не ошибка.** Либо за период не появилось новых данных, либо выбран старый файл. Сформируйте свежую выгрузку из 1С и загрузите её |
| 🔴 **«Parse error: …»**                                           | Система не смогла разобрать файл — изменился вид отчёта (другие колонки, свёрнутые группировки, лишние листы) | Сформировать отчёт в **стандартном виде** (раздел 3) и повторить. Если не помогло — см. раздел 10                                      |
| Статус `**failed`** в истории импортов                            | Импорт не завершился, данные **не записаны**                                                                  | Повторить загрузку. Если повторяется — см. раздел 10                                                                                   |
| Долго грузится / «крутится»                                       | Большой файл — это нормально                                                                                  | Подождать, вкладку не закрывать. Если «висит» больше 2 минут — обновить страницу (F5) и проверить историю импортов                     |
| Не открывается [http://ceo.pass24pro.ru](http://ceo.pass24pro.ru) | Сайт недоступен                                                                                               | Проверить интернет; попробовать позже; если не открывается долго — см. раздел 10                                                       |


**Перезаливать файл безопасно.** Повторная загрузка ничего не задваивает: одинаковые строки
система отбрасывает, одинаковый файл целиком — отклоняет (409). Если сомневаетесь, прошёл ли
импорт, — просто проверьте «Историю импортов» (раздел 5).

## 9. Чек-листы

### Ежедневно (платежи)

- Сформировать в 1С «Оплата от покупателей» с 1 января по сегодня → сохранить `.xlsx`
- CEO24 → меню «Импорт» → «Тип файла» = `Оплата от покупателей (1С)`
- «Выбрать .xls / .xlsx» → указать файл → дождаться 🟢 зелёного сообщения
- «История импортов»: верхняя строка, статус `completed`
- Если «Новых» > 0 — сообщить руководителю продаж
- Открыть «Дашборд», проверить, что собираемость и поступления обновились

### Еженедельно (долги)

- Сформировать в 1С «Задолженность покупателей» за текущий год (уровни раскрыты) → `.xlsx`
- CEO24 → меню «Импорт» → «Тип файла» = `Задолженность покупателей (1С)`
- «Выбрать .xls / .xlsx» → указать файл → дождаться 🟢 зелёного сообщения
- «История импортов»: верхняя строка, статус `completed`
- Если «Новых» > 0 — сообщить руководителю продаж
- Открыть «Должники» и «Реестр клиентов», проверить, что суммы долга обновились

## 10. Куда обращаться

При повторяющихся ошибках, недоступности сайта или вопросах по входу — обратиться к
администратору системы (Алексей Хромов). При обращении полезно приложить:

- название и тип файла, который загружали;
- точный текст красного сообщения об ошибке (можно скриншот экрана «Импорт»);
- дату и время попытки.
